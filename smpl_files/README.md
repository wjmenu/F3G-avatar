# SMPL-X model files (download required)

Download [SMPL-X](https://smpl-x.is.tue.mpg.de/download.php) and place the `.npz` / `.pkl` files under:

```
smpl_files/smplx/
```

The template pipeline and training code expect this path (or pass `--smplx_model_path` explicitly).

The `mano/` text files in this folder are small auxiliary assets and are included in the repo.
